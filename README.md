# 🚀 JavaScript Moderno: Guía Definitiva (+20 Proyectos)

Este repositorio contiene mis avances, ejercicios y proyectos desarrollados en el curso **"JavaScript Moderno Guía Definitiva Construye +20 Proyectos"**. El objetivo es dominar el lenguaje desde sus bases hasta conceptos avanzados, incluyendo el stack MERN y consumo de APIs.

---

## 📚 Información del Curso

- **Nombre:** JavaScript Moderno Guía Definitiva Construye +20 Proyectos
- **Contenido:** Fundamentos, Programación Orientada a Objetos, Asincronismo, APIs, y Stack MERN.
- **Plataforma:** Udemy

---

## 🛠️ Tecnologías y Conceptos Aprendidos

- **Fundamentos Modernos:** Let/const, Arrow Functions, Template Literals, Destructuring.
- **Manipulación del DOM:** Selección de elementos, Event Listeners, creación de HTML dinámico.
- **Programación Orientada a Objetos:** Prototypes (ES5) y Clases (ES6).
- **Asincronismo:** Callbacks, Promises, Fetch API y Async / Await.
- **Almacenamiento:** LocalStorage e IndexedDB.
- **Stack MERN:** MongoDB, Express, React y Node.js (Proyecto IA).
